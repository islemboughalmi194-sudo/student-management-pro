# Student Management Pro 🎓

Application web de démonstration pour la gestion des étudiants.

## Fonctionnalités
- Dashboard avec statistiques.
- Liste des étudiants et recherche.
- Filtrage par formation.
- Ajout et suppression d'étudiants.
- Exportation de la liste en fichier CSV.
- Interface responsive pour ordinateur et mobile.

## Technologies
- HTML5
- CSS3
- JavaScript (vanilla)

## Lancer le projet
Aucune installation n'est nécessaire. Ouvrez simplement `index.html` dans un navigateur.

## Publier sur GitHub
1. Créez un nouveau repository GitHub nommé `student-management-pro`.
2. Ouvrez Git Bash dans ce dossier.
3. Exécutez les commandes ci-dessous en remplaçant `VOTRE-URL-GITHUB` par l'URL de votre repository.

```bash
git init
git add .
git commit -m "Initial commit - Student Management Pro"
git branch -M main
git remote add origin VOTRE-URL-GITHUB
git push -u origin main
```

> Les données sont fictives et conservées uniquement en mémoire pendant l'utilisation. Ce projet n'utilise pas encore de backend ni de base de données.
